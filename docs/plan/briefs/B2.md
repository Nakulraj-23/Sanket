# B2 — Baseline model, explanation, routing, retrain gate (Sonnet)
Read also: handoffs B0, B1, Q1. Own: `sanket/models/{baseline,evaluate,train_baseline}.py`, `sanket/routing/`,
`sanket/retrain.py`, `artifacts/models/`, `artifacts/registry.json`, `tests/model/`, `tests/unit/test_routing*.py`.
Build:
1. `BaselineModel` per CONTRACTS: TF-IDF word 1-2 grams + character 2-5 grams (`char_wb`), sublinear tf, then
   multinomial logistic regression. Small grid on `val` only: C in {5, 10, 20}, with and without character grams.
   Store coefficients as float32 so `model.joblib` stays under 10 MB; report what that cost in accuracy.
2. `explain(text, intent, k)`: contribution of each present term = coefficient x TF-IDF value; top k by value with
   `heapq.nlargest`. Test: all contributions plus the intercept equal the intent's raw score (to 1e-5).
3. `routing/decide.py` per CONTRACTS (pure). Tests: team probabilities sum to 1; each threshold rule fires.
4. `routing/thresholds.py`: choose `tau_team`, `tau_high`, `oov_max` on `val` by the CONTRACTS rules; write `thresholds.json`.
5. `evaluate.py`: on `val` and `test`: intent accuracy and macro-F1, team accuracy, urgency macro-F1, high-urgency
   recall and precision at `tau_high`, share auto-routed and accuracy of auto-routed tickets, ECE (10 bins),
   coverage-versus-accuracy table, 10 most confused intent pairs. Stress sets: typo test set (`add_typos`, rate 0.1)
   and `hinglish.csv`: accuracy, share sent to a human, share wrong **and** auto-routed (silent failures).
6. `train_baseline.py` (`make train`): train on `train`, write `artifacts/models/v1/` (model, thresholds,
   `reference.json` in the CONTRACTS shape, `card.json`) and `registry.json` with champion `v1`. Under 2 minutes.
7. Ablation, logged in `docs/EXPERIMENTS.md`: a direct 7-team LR versus the summed-probability team prediction.
   Report both honestly; do not change the design if the direct model is slightly better (say so in the handoff).
8. `retrain.py` (`make retrain`): read reviewed tickets from the DB (`final_intent`), need at least `--min-new 50`,
   run quality checks, train candidate on train + reviewed, evaluate champion and candidate on `test`, apply the
   promote gate from CONTRACTS in a function `gate(champion_metrics, candidate_metrics) -> (bool, reasons)`, write
   the candidate directory and a registry entry, switch champion only if promoted. Flag `--sabotage 0.3` flips that
   share of the new labels **and** of train labels. Flag `--from-csv` for tests without a DB.
9. `tests/model/` quality gates on the committed champion: intent macro-F1 >= measured − 0.02 (never below 0.85),
   team accuracy >= 0.95, high-urgency recall >= 0.95, auto-routed accuracy >= 0.98, single-ticket p95 < 20 ms,
   artifact size limits, sabotage run is rejected, an identical retrain is not rejected.
Done when: `make train` and `pytest tests/model tests/unit` pass. Handoff: every metric above, the thresholds,
model file size, grid results, ablation result.
