## Choices to know
- Thresholds are read from `thresholds.json` (4 keys); `retrain` is not called by the API or seed.
- `GET /tickets/{id}` re-runs the models on the stored cleaned text (raw text is gone, so `before_masked` shows the stored text);
  stage times there are fresh, `prediction` fields are the stored ones. Predictions table has no top_intents/team_probs.
- `latency_ms` = clean + classify + explain + route. `/metrics.latency_by_model` is keyed by model version `{avg_ms, n}`
  (SQLite has no percentiles), not the fixture's baseline/nn p50/p95.
- Shown terms hide character pieces that only repeat a shown word (Q2 finding). Review urgency defaults from the taxonomy on override.
- Ingest stage code is `validate`, clean stage is `clean` (which calls `redact`). `/monitor/drift` returns a fresh unsaved report if none stored.
