# V1 - Vercel-only deployment (single project, same origin)

Status: prepared, not deployed (no credentials used).

## Added
- `api/index.py`: exports `app`; DB at `/tmp/sanket.db`, seeds `SANKET_SEED_TICKETS` (default 250), models read from `artifacts/`.
- `requirements.txt`: serving only (numpy, pandas, scikit-learn, scipy, joblib, pyyaml, fastapi, sqlalchemy, pydantic, pydantic-settings), pinned to the venv.
- `vercel.json` (build, `web/dist`, rewrites, `includeFiles`), `.vercelignore`.
- `web/src/api.js`: `VITE_SAME_ORIGIN=1` or `VITE_API_URL=/` = relative `/api`, 12 s health timeout; Replay fallback kept.
- `docs/DEPLOY.md`: section "Vercel-only deployment".

## Changed for graceful no-ONNX
- `sanket/service.py` `load_nn` returns None without onnxruntime; `Runtime.nn` may be None.
- `/api/compare`: `nn` optional plus `nn_note`; stage "classify" text and `web/src/Drawer.jsx` say it is not available.
- `scripts/seed.py`: `main(n_tickets, rt)`; queue sample no longer fails on small seeds. `sanket/api/app.py` keeps a pre-attached runtime.

## Verified
- Scratch venv with only requirements.txt (+httpx for TestClient): health, POST /tickets, queue, review, 409 on repeat, compare, stages OK.
- Cold start locally (import + load + seed 250): about 3.6 s (400 tickets: 4.7 s). Site-packages 441 MB, app files about 5.7 MB.
- `make lint` clean, `make test` 259 passed 1 xfailed, web build and `npm test` 6 passed.

## Risks
- Unpacked size about 450 MB (pandas and scipy dominate); near the 500 MB unpacked limit, not verified on Vercel.
- Not tested on real Vercel: `includeFiles` globs, rewrite to `/api/index`, whether lifespan runs (handled either way).
- Stateless: reviews not shared across instances (documented).
