# B5 handoff: dashboard (web/)
Status: done. Build, replay e2e (6/6) and live e2e (5/5, real API, stopped after) pass. Q3 web fixes applied.
## What exists
- `web/`: React 18.3.1 + Vite 5.4.8, plain JS, one CSS file. `src/api.js` (all CONTRACTS calls + replay source),
  `App.jsx`, `Pipeline.jsx` (7 cards, return arrow), `Drawer.jsx` (4 tabs, Esc closes), `ReviewForm.jsx`, `Panels.jsx`
  (queue, monitor, model), `samples.js` (six chips). `vercel.json`, `e2e/replay.spec.js`, `e2e/live.spec.js` (@live).
- `web/scripts/fixtures_to_replay.mjs` builds `web/public/replay.json` from `fixtures/` (replace with B4's real file).

## How to run
- Replay: `cd web && npm install && npm run dev` (no API running, badge reads Replay). `make web` does the same.
- Live: `VITE_API_URL=http://localhost:8000 npm run dev`; on load `/health` (4 s timeout) decides. In replay it retries every 15 s.
- Tests: `PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npm test` (replay only, skips @live; CI must call `npm test`, not `npx playwright test`). Live: `SANKET_LIVE_API=http://localhost:8000 npm run test:live` (port 5173 = the CORS default).
- Build: `npm run build` (generates replay.json first only if missing).
