# B5 handoff: dashboard (web/)
Status: done against fixtures; build and replay e2e pass; live mode written, not run (no API yet).
## What exists
- `web/`: React 18.3.1 + Vite 5.4.8, plain JS, one CSS file. `src/api.js` (all CONTRACTS calls + replay source),
  `App.jsx`, `Pipeline.jsx` (7 cards, return arrow), `Drawer.jsx` (4 tabs, Esc closes), `ReviewForm.jsx`, `Panels.jsx`
  (queue, monitor, model), `samples.js` (six chips). `vercel.json`, `e2e/replay.spec.js`, `e2e/live.spec.js` (@live).
- `web/scripts/fixtures_to_replay.mjs` builds `web/public/replay.json` from `fixtures/` (replace with B4's real file).

## How to run
- Replay: `cd web && npm install && npm run dev` (no API running, badge reads Replay). `make web` does the same.
- Live: `VITE_API_URL=http://localhost:8000 npm run dev`; on load `/health` (4 s timeout) decides. In replay it retries every 15 s.
- Tests: `PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npm test` (replay). Live: `SANKET_LIVE_API=http://localhost:8000 npm run test:live`.
- Build: `npm run build` (generates replay.json first only if missing).

  The real `/stages` must return all seven ids: ingest clean classify explain route review monitor.
- Replay `samples` (six, indexed like the chips) are derived from two fixtures with edited text, so explain terms repeat. B4's
  `replay.json` should supply real ones; sample order must be: clear, urgent fraud, ambiguous, fake PII, Hinglish, gibberish.
- `replay.compare` is keyed by sample index as a string. `drift_after_scenario` is the red fixture.
- Live-mode Fake PII chip posts the raw fake card; the API must redact it. Monitor card shows drift before any ticket.
- Drawer is not focus-trapped.
- `/health` must return `status: "ok"`; any other body counts as "no API" (a static host may answer with index.html).
